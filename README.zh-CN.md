# Job Compass · 简历驱动的本地求职工具

这是一个每个人独立运行的本地工具。上传自己的简历 PDF，核对技能和方向，再搜索岗位、记录投递与跟进。

## 开始使用

需要 Python 3.11+。在项目文件夹里执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

打开 http://127.0.0.1:18866 。安装完成后，Windows 用户也可以双击 `start.cmd`。

1. 打开「简历与方向」，上传可选择文字的 PDF，或直接手动填写方向。
2. 核对目标岗位、技能、关键词、国家、优先城市和岗位类型。
3. 点击「保存并搜索」。城市只影响优先级，其他地区仍可保留。
4. 实际投递后，在卡片上点击「记录已投」，按当天日期记入申请表。
5. 「我的投递」直接显示每次进展。填写明确的拒绝备注会同步状态；也可以一键标记已拒绝，变灰并置底。
6. 需要每天更新时，在偏好设置中启用。默认德国时间 09:00；关机、休眠或服务未运行时不能更新。

## 隐私

项目初始没有任何人的简历、姓名、履历、申请、备注、截图、日志或数据库。PDF 和提取全文仅在本机内存里处理，不保存、不上传到模型服务。只有核对后的技能和搜索设置写入 `data/profile.json`。搜索会向公开服务发送已确认的关键词与国家，不会发送 PDF 或简历全文。

`data/`、虚拟环境、PDF、截图、日志和数据库已列入 Git 忽略规则。发布压缩包采用源文件白名单，不会把运行数据打包进去。修改或增加源文件后仍应检查内容，自动扫描无法识别所有可能的私人信息。

## 搜索与解析范围

德国自动来源包括 Arbeitnow、Fraunhofer 和网页搜索；奥地利、瑞士的自动覆盖较少，以网页检索及外部搜索入口为主。工具不保证穷尽全网，也不保证页面可访问的职位仍然开放。空搜索源会明确报错；可以使用界面上生成的外部搜索链接继续查找。

简历解析采用可检查的关键词规则，不是 AI 模型。扫描件、加密文件、超过 5 MB 或 15 页的 PDF 暂不支持。未识别的技能和岗位方向可以手动补充。研究与模型训练是可选的 AI 专题视图，不会把其他专业强行归到 AI。

## 开发和开源

```powershell
python -m unittest discover -s tests -v
python scripts/package_release.py --check
python scripts/package_release.py
```

生成的 `dist/job-compass-open-source.zip` 只包含程序、说明、通用测试和 MIT 许可证，可解压后上传到自己的 GitHub 仓库。本工具不会自动发布 GitHub，不会自动向公司投递。

更多配置与跨平台启动方式见 [English README](README.md)。
