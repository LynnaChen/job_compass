# Contributing

Use synthetic resumes and isolated test databases. Keep matching rules explainable, make unavailable sources visible, and avoid inferring qualifications that are not supported by the resume or vacancy.

Run `python -m unittest discover -s tests -v` and `python scripts/package_release.py --check` before proposing a change. Do not add real CVs, private contact information, local paths, API keys, screenshots of applications, databases or logs. New files must be intentionally added to the release allowlist if they belong in the public source archive.

Contributions are provided under the MIT license. The repository currently uses a Chinese interface with English and Chinese documentation.
